# David Raigoza Studio // Business Portfolio

Production-ready digital portfolio and professional services platform for [David Raigoza Studio](https://davidraigoza.online), specializing in product design engineering, software architecture, and AI systems integration.

---

## 🛠️ Tech Stack

- **Framework & Build:** [Vite](https://vitejs.dev/), React, TypeScript
- **Styling & UI:** Tailwind CSS, custom architectural design system
- **3D & Interactive:** Three.js, React Three Fiber, Blender assets
- **Deployment:** Vercel

---
